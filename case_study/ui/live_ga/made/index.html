1. Dynamic Programming

Key Concepts

  • Optimal substructure: Optimal solution to the problem contains optimal solutions to subproblems.
  • Overlapping subproblems: Same subproblems are solved many times in recursion.
  • Bottom-up (table-filling) vs. top-down (memoization).
  • Space optimisation: often only the last row/column is needed.

Classic Problems & Running Times

Key Formulas

/* LCS: */
L[i][j] = 0                                    if i==0 or j==0
L[i][j] = L[i-1][j-1]+1                        if x[i]==y[j]
L[i][j] = max(L[i-1][j], L[i][j-1])            if x[i]!=y[j]

/* 0/1 Knapsack: */
K[i][w] = K[i-1][w]                           if w_i > w
K[i][w] = max(K[i-1][w], v_i + K[i-1][w-w_i]) if w_i <= w

/* Matrix Chain: */
m[i][j] = min{ m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j] }  for k in [i..j-1]
/* p[] holds dimensions: n matrices of sizes p[0]x p[1], p[1]x p[2], ... */

/* LIS: */
dp[i] = 1 + max(dp[j])  for j < i where A[j] < A[i]
/* Answer = max(dp) — can be O(n log n) with patience sorting / binary search */

Multiple-Choice Traps

“Knapsack DP is O(nW)—this is pseudo-polynomial, not polynomial, because W is a value not an input length.”
“Greedy for shortest path (Dijkstra) works for non-negative weights; not for negative weights (use Bellman-Ford O(VE)).”
“LCS gives length in O(nm); to reconstruct the string, trace back through the table.”
“For chain matrix multiplication, the number of multiplications depends on parenthesisation order; greedy left-to-right is not optimal (e.g., (10×100)(100×5) vs 10(100×5)).”

Self-Check Questions

Q: What is the time complexity of LIS using the standard DP approach, and can it be improved?
Standard DP: O(n2) time, O(n) space. Can be improved to O(n log n) time using patience sorting with binary search (maintain an array of smallest tail elements for increasing subsequences of each length).
Q: Why is the 0/1 Knapsack DP not truly polynomial time?
The running time is O(nW). W is a value, not the number of bits needed to represent it. In binary, W requires log W bits, so O(nW) = O(n · 2log W) is exponential in the input size. Hence it is pseudo-polynomial.
Q: In LCS, if X = “ABCBDAB” and Y = “BDCAB”, what is the LCS length?
LCS length = 4. One valid LCS is “BCAB” (others: “BDAB”, “BCAB”).

2. Divide & Conquer

Key Concepts

  • Recurrence: T(n) = a · T(n/b) + f(n)
  • Master Theorem: Compare f(n) with nlogba.

Master Theorem

RelationCaseResult
f(n) = O(nlogba −−ε)1 — work at leavesT(n) = Θ(nlogba)
f(n) = Θ(nlogba · logkn)2 — work balancedT(n) = Θ(nlogba · logk+1n)
f(n) = Ω(nlogba + ε)3 — work at rootT(n) = Θ(f(n))

Classic Problems & Running Times

ProblemNaiveD&CNotes
Integer multiplication (Karatsuba)O(n2)O(nlog23) ≈ O(n1.58)3 recursive calls instead of 4
Matrix multiplication (Strassen)O(n3)O(nlog27) ≈ O(n2.81)7 recursive calls
Fast Fourier Transform (FFT)O(n2)O(n log n)Evaluate poly at roots of unity, multiply pointwise, interpolate
Median of two sorted arraysO(n+m)O(log(min(n,m)))Binary search on partition
Closer pair of pointsO(n2)O(n log n)Sweep + strip of width d

Key Details

  • Karatsuba: Split each n-digit number into high/low halves. Compute z0 = x0y0, z2 = x1y1, z1 = (x0+x1)(y0+y1) − z0 − z2. Recurrence: T(n) = 3T(n/2) + O(n) → O(nlog23).
  • FFT: O(n log n) polynomial multiplication via evaluation at nth roots of unity, pointwise multiply, inverse FFT. Uses butterfly operations. Number-Theoretic Transform (NTT) replaces complex roots with modular roots of unity.

Multiple-Choice Traps

“Master Theorem does not apply when f(n) is in-between cases or when a < 1. It also fails for T(n) = 2T(n/2) + n/log n.”
“FFT multiplies polynomials in O(n log n), but converting back to coefficient form requires the inverse FFT (divide by n).”
“Strassen is O(n2.81) but has a large constant; it is only faster for very large matrices.”

Self-Check Questions

Q: Solve T(n) = 4T(n/2) + n. What is the complexity?
a=4, b=2, logba = log24 = 2. f(n) = n = O(n2 −−1). Case 1 applies: T(n) = Θ(n2).
Q: How many recursive multiplications does Karatsuba use vs. schoolbook?
Schoolbook: 4 multiplications of n/2-digit numbers. Karatsuba: 3 multiplications (uses addition/subtraction to eliminate one).

3. Randomized Algorithms & RSA

Key Concepts

  • Modular arithmetic: (a · b) mod n, (a + b) mod n.
  • Modular exponentiation (square-and-multiply): O(log e) modular multiplications.
  • Extended Euclidean Algorithm: Finds gcd(a,b) and coefficients x, y such that ax + by = gcd(a,b). Used to compute modular inverses.
  • Fermat’s Little Theorem: If p is prime and a not divisible by p, then ap−1 ≡ 1 (mod p).
  • Euler’s Totient Theorem: aφ(n) ≡ 1 (mod n) when gcd(a,n)=1.
  • Chinese Remainder Theorem (CRT): System of congruences with pairwise-coprime moduli has a unique solution mod the product.

Primality Testing

TestTypeRunning TimeNotes

RSA Cryptosystem

StepDetails
Key GenPick large primes p, q. n = pq. φ(n) = (p−1)(q−1). Choose e coprime to φ(n). Compute d = e−1 mod φ(n). Public key: (n, e). Private key: (n, d).
Encryptc = me mod n

Modular Inverse (Extended Euclidean)

function ExtendedGCD(a, b):
  if b == 0: return (a, 1, 0)
  (g, x1, y1) = ExtendedGCD(b, a % b)
  return (g, y1, x1 - (a // b) * y1)

# To find e^(-1) mod phi:
(g, x, _) = ExtendedGCD(e, phi)
inverse = x mod phi

Multiple-Choice Traps

“Fermat test: an−1 ≡ 1 (mod n) is necessary but not sufficient for primality. Carmichael numbers pass for all a coprime to n.”
“Miller-Rabin: write n−1 = 2s·d (d odd). Check ad ≡ 1 (mod n) OR some a2rd ≡ −1 (mod n) for 0 ≤ r < s. If neither, n is definitely composite.”
“RSA with small e=3 is insecure if the message m is small (m < n1/3): the ciphertext c = m3 can be recovered by taking the cube root without modular reduction.”
“φ(pq) = (p−1)(q−1), not pq − 1 (that’s only for prime p).”

Self-Check Questions

Q: Given p=61, q=53, e=17. Find d (the private exponent).
n = 61 · 53 = 3233. φ(n) = 60 · 52 = 3120. d = 17−1 mod 3120. Using Extended Euclidean: 17 · 2753 − 1 · 3120 = 1. So d = 2753.
Q: Why is Miller-Rabin better than Fermat for primality testing?
Fermat test is fooled by Carmichael numbers (which pass for all bases coprime to n). Miller-Rabin’s “strong” test catches all composites with probability ≥ 3/4 per random base, and has no Carmichael-number counterexamples.

4. Graph Algorithms

Key Concepts & Running Times

Graph Edge Types (DFS classification)

  • Tree edge: Edge in the DFS spanning tree.
  • Back edge: Edge to an ancestor (in directed graphs, indicates a cycle).
  • Forward edge: Edge to a descendant (not in tree).
  • Cross edge: Edge between different DFS trees or non-ancestor/descendant nodes.

2-SAT

  • Given a boolean formula in CNF with exactly 2 literals per clause, is it satisfiable?
  • Build an implication graph: each literal x gets a node “x” and a node “¬x”. Clause (a ∨ b) becomes (¬a → b) and (¬b → a).
  • 2-SAT is satisfiable iff no variable and its negation are in the same SCC.
  • Time: O(V + E) for building graph + O(V + E) for SCC. Total: O(V + E).

Multiple-Choice Traps

“Dijkstra fails with negative edge weights (even if no negative cycle exists). Use Bellman-Ford O(VE) or SPFA.”
“MST is not the same as Shortest Path Tree. Kruskal’s/Prim’s minimise total edge weight; Dijkstra minimises path distance.”
“In a directed graph, a back edge in DFS always means a cycle exists. In an undirected graph, only edges to already-visited (non-parent) nodes matter.”
“Topological sort = DFS with decreasing finish time (post-order stack). Only valid on a DAG.”
“Kruskal’s and Prim’s both produce MSTs, but they can differ if there are ties in edge weights. Both are correct.”

Self-Check Questions

Q: Can a graph have multiple MSTs? Under what conditions?
Yes, if there are edges with equal weights that can be swapped. If all edge weights are distinct, the MST is unique.
Q: For 2-SAT, why does finding a variable and its negation in the same SCC mean unsatisfiable?
If x and ¬x are in the same SCC, there is a path x → ... → ¬x and ¬x → ... → x, meaning x → ¬x and ¬x → x — i.e., x ↔ ¬x. No truth assignment can satisfy both.
Q: What is the time complexity of finding SCCs in a directed graph?
O(V + E) using either Kosaraju’s algorithm (2 DFS passes) or Tarjan’s algorithm (single DFS pass with low-link values).

5. Max-Flow & Min-Cut

Key Concepts

  • Flow network: directed graph G = (V, E), source s, sink t, capacity c(u,v) ≥ 0 on each edge.
  • Flow properties: Capacity constraint (f(u,v) ≤ c(u,v)), skew symmetry (f(u,v) = −f(v,u)), flow conservation (inflow = outflow at every node except s, t).
  • Residual network Gf: For each edge (u,v), residual capacity = c(u,v) − f(u,v). Also adds back-edges if f(u,v) > 0.
  • Augmenting path: A path from s to t in the residual network.

Algorithms & Running Times

AlgorithmRunning TimeNotes
Ford-FulkersonO(C · |E|)C = max flow value. Pseudo-polynomial. Depends on augmenting path choice. DFS-based.
Edmonds-KarpO(V · E2)BFS to find shortest augmenting path (by # edges). Number of augmentations: O(VE).
Orlin (2013)O(VE)Best known exact algorithm for general graphs.

Max-Flow = Min-Cut Theorem

  • For any flow f and any s-t cut (L,R), size(f) ≤ capacity(L,R).
  • The maximum flow equals the minimum cut capacity.
  • After max-flow, the min-cut (L,R) is: L = {vertices reachable from s in Gf*}, R = V − L.
  • All edges from L to R are saturated (f(u,v) = c(u,v)). All edges from R to L have f(u,v) = 0.

Multiple-Choice Traps

“Ford-Fulkerson is O(C · |E|) — not polynomial in input size (C can be exponential in log C bits). Edmonds-Karp fixes this to O(VE2).”
“A cut (L,R) in max-flow must separate s and t (s ∈ L, t ∈ R). A general partition of V that does not separate s and t is not an s-t cut.”
“The min-cut is the sum of capacities of edges from L to R only — edges from R to L are not counted.”
“Ford-Fulkerson stops when there is no path from s to t in the residual network — not when no edges are saturated.”

Self-Check Questions

Q: In Edmonds-Karp, why does BFS (instead of DFS) guarantee polynomial running time?
BFS finds the shortest augmenting path (by # edges). Each augmentation increases the distance of the shortest s-t path in the residual graph. The distance can increase at most O(V) times, and each BFS takes O(E), so total augmentations = O(VE), each O(E) → O(VE2).
Q: How do you find the minimum cut from a maximum flow?
After computing max-flow f*, let L be the set of vertices reachable from s in the residual graph Gf*. Let R = V − L. The min-cut is the set of original edges from L to R. Its capacity = max flow value.

6. Linear Programming

Standard Form

Primal (standard form):
  min c^T x
  s.t. Ax = b
       x >= 0

Dual:
  max b^T y
  s.t. A^T y <= c
       y free (unconstrained)

Duality Rules

PrimalDual
min problemmax problem
x ≥ 0dual constraint: ≤
x freedual constraint: =
constraint: =dual variable: free
constraint: ≥dual variable: ≥ 0
constraint: ≤dual variable: ≤ 0

Key Theorems

  • Weak Duality: For any feasible primal x and dual y: cTx ≥ bTy. Primal objective ≥ dual objective.
  • Strong Duality: If either the primal or dual has an optimal solution, so does the other, and their optimal values are equal.
  • Complementary Slackness: At optimality: xj · (cj − (ATy)j) = 0 for all j. If a primal variable is positive, the corresponding dual constraint is tight (equality).

Simplex Algorithm

  • Starts at a vertex of the feasible region (a basic feasible solution).
  • Iteratively moves to an adjacent vertex with a better objective value.
  • Terminates when no improving adjacent vertex exists → optimal.
  • Worst-case: exponential (Klee-Minty cube). But in practice, very fast on real-world problems.
  • LP is in P (Karmarkar’s interior-point method is polynomial; simplex is fast empirically). ILP (integer LP) is NP-complete.

Max-Flow as LP

Primal (max-flow):
  max sum of flow out of s
  s.t. flow conservation at each node
       0 <= f(u,v) <= c(u,v)

Dual (min-cut):
  min sum of cut capacities
  s.t. variables y_v for each vertex
       y_s = 1, y_t = 0
       y_v - y_u <= c(u,v) for each edge (u,v)

Multiple-Choice Traps

“LP (linear programming) is in P, but ILP (integer linear programming) is NP-complete. Don’t confuse them on the exam.”
“Weak duality: primal (min) ≥ dual (max). Don’t flip the inequality sign on the exam.”
“The simplex algorithm can cycle in theory. In practice, Bland’s rule (pick lowest-index entering/exiting variable) prevents cycling.”
“An LP can be unbounded or infeasible. These are possible outcomes — not just ‘optimal solution found.’

Self-Check Questions

Q: If a primal LP is unbounded, what does that imply about the dual?
By weak duality, if the primal (min) is unbounded below (−∞), the dual must be infeasible. You cannot have a feasible dual providing a lower bound if the primal goes to −∞.
Q: Is the dual of the dual always the primal?
Yes. Taking the dual of the dual LP recovers the original primal LP exactly.
Q: What does complementary slackness tell you?
At optimality, for each primal variable xj and its corresponding dual slack sj = cj − (ATy)j: either xj = 0 or sj = 0 (or both). This lets you recover one optimal solution if you know the other.

7. NP-Completeness

Key Definitions

  • P: Problems solvable in polynomial time.
  • NP: Problems whose solutions can be verified in polynomial time.
  • NP-hard: At least as hard as any problem in NP (may not even be in NP).
  • NP-complete: In NP and NP-hard. Hardest problems in NP (assuming P ≠ NP).
  • Halting Problem: “Does program P halt on input I?” — undecidable (not in NP, not even verifiable in poly time).

Classic NP-Complete Problems

ProblemDecision Version
SATIs there a truth assignment satisfying a boolean formula?
3-SATIs there a truth assignment satisfying a CNF formula with ≤ 3 literals per clause?
Vertex Cover (VC)Does G have a vertex cover of size ≤ k?
Independent Set (IS)Does G have an independent set of size ≥ k?
CliqueDoes G have a clique of size ≥ k?
Hamiltonian Cycle (HC)Does G have a cycle visiting every vertex exactly once?
Rudrata PathDoes G have a path visiting every vertex exactly once?
Traveling Salesman (TSP)Does a tour of cost ≤ K exist?
Subset SumIs there a subset summing to target t?
3-ColoringCan vertices be colored with 3 colors so no adjacent vertices share a color?
ILPDoes Ax ≤ b have an integer solution x ≥ 0?
3D MatchingGiven sets X,Y,Z and triples, is there a matching covering all elements?

Key Reductions

  • SAT → 3-SAT: Break clauses with >3 literals using auxiliary variables.
  • 3-SAT → Vertex Cover: For each clause (a ∨ b ∨ c), create a triangle of 3 nodes. Connect conflicting literals. Cover size = 2n + k.
  • Vertex Cover → Independent Set: S is a vertex cover iff V − S is an independent set. Same graph, same k.
  • Independent Set → Clique: S is an IS in G iff S is a clique in G’ (complement graph).
  • Vertex Cover → Hamiltonian Cycle: Replace each edge with a “gadget” (diamond-shaped path). HC exists iff VC exists.
  • 3-Coloring → Clique: If G has a clique of size 3, then G is 3-colorable iff G’ has a clique of size k.
  • Subset Sum → ILP: Special case with binary variables and one constraint.

How to Prove a Problem is NP-Complete

  1. In NP: Show a certificate (witness) can be verified in polynomial time.
  2. NP-hard: Reduce a known NP-complete problem to the new problem in polynomial time.
  3. Chain: start from SAT/3-SAT (first proved NP-complete by Cook-Levin), then reduce through the web of known NP-complete problems.

Multiple-Choice Traps

“If P = NP, every NP-complete problem becomes solvable in polynomial time. If P ≠ NP, none of them do.”
“The Halting Problem is undecidable, not NP-complete. It cannot even be verified in polynomial time (it is ∉ NP).”
“Vertex Cover + Independent Set: S is a VC ↔ V − S is an IS. They are complements on the same graph. Don’t reduce to different graphs.”
“TSP with triangle inequality (metric TSP) can be approximated (2-approx via MST), but the decision version is still NP-complete.”
“A problem being NP-complete does not mean it cannot be solved in polynomial time for special cases (e.g., 2-SAT is in P, but 3-SAT is NP-complete).”

Self-Check Questions

Q: What is the difference between NP-hard and NP-complete?
NP-hard: at least as hard as any NP problem (may not be in NP). NP-complete: in NP and NP-hard. All NP-complete problems are NP-hard, but not all NP-hard problems are NP-complete (e.g., Halting Problem is NP-hard but not in NP).
Q: How do you reduce Vertex Cover to Independent Set?
On the same graph G: S is a vertex cover of size k iff V − S is an independent set of size |V| − k. This is a trivial (polynomial-time) reduction.
Q: Why is 2-SAT in P but 3-SAT NP-complete?
2-SAT can be solved by building an implication graph and checking SCCs (O(V+E)). The implication structure guarantees consistency. With 3+ literals per clause, the implication graph no longer captures all constraints, and the problem becomes NP-complete.

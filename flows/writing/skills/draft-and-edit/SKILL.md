# Draft and edit

1. Pin down the reader, the purpose and the length before writing. Recall shared memory for house style.
2. Outline: the headings and the one point each section makes.
3. Draft into a Markdown file in the workspace (name it after the subject).
4. Edit pass: cut filler, keep sentences short, check every fact against its source, keep one voice.
5. Record the document and any style decisions in shared memory (memory_record kind=document).

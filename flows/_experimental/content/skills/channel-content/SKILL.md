# Channel content

1. Recall shared memory for brand voice and past posts (memory_recall "voice", "post").
2. Write three angles (hook + point) and pick one, saying why.
3. Draft one piece per channel in the workspace, each within that channel's length.
4. Review: voice, claims, links, call to action.
5. Record what was published-ready and the voice notes in shared memory (memory_record kind=content).
